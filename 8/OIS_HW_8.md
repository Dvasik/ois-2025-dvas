## Задача 1. Порядки элементов мультипликативной группы $GF(5^2)$

### Построение поля $GF(25)$

Поле $GF(5^2) = GF(25)$ строится как $GF(5)[x] / p(x)$, где $p(x)$ — неприводимый многочлен степени 2 над $GF(5)$.

Возьмём неприводимый многочлен:

$$p(x) = x^2 + x + 2$$

Проверим неприводимость — он не имеет корней в $GF(5)$:

| $a$ | $a^2 + a + 2 \pmod{5}$ |
| --- | ---------------------- |
| 0   | 2                      |
| 1   | 4                      |
| 2   | 3                      |
| 3   | 4                      |
| 4   | 2                      |

Корней нет $\Rightarrow$ многочлен неприводим над $GF(5)$. 

### Примитивный элемент

Пусть $\alpha$ — корень $p(x)$, т.е. $\alpha^2 + \alpha + 2 = 0$, откуда:

$$\alpha^2 = -\alpha - 2 = 4\alpha + 3 \pmod{5}$$

Мультипликативная группа $GF(25)^*$ имеет порядок:

$$|GF(25)^*| = 24$$

Делители числа 24: $1, 2, 3, 4, 6, 8, 12, 24$.

### Степени примитивного элемента $\alpha$

Рекуррентное правило умножения: если $\alpha^k = a + b\alpha$, то

## Задача 2. $(15, 4)$-код с проверочным полиномом $h(x) = 1 + x + x^4$

### Основные параметры

Циклический код $(n,k) = (15, 4)$ с проверочным полиномом $h(x) = 1 + x + x^4$.

Порождающий полином находится из соотношения:

$$g(x) = \frac{x^{15} + 1}{h(x)} = \frac{x^{15} + 1}{1 + x + x^4}$$

$$g(x) = x^{11} + x^{10} + x^9 + x^8 + x^6 + x^4 + x^2 + x + 1$$

Степень $g(x)$ равна $n - k = 15 - 4 = 11$ ✓

---

### Проверка: код максимальной длины

Код является кодом максимальной длины (МДР, $[2^m - 1,\; m]$), если $h(x)$ — **примитивный многочлен** степени $m$.

Здесь $h(x) = x^4 + x + 1$, $m = 4$, $n = 2^4 - 1 = 15$ 

#### Шаг 1 — Неприводимость $h(x)$

Проверяем отсутствие корней в $GF(2)$:

$$h(0) = 1 \neq 0, \qquad h(1) = 1+1+1 = 1 \neq 0$$

Нет делителей степени 2: единственный неприводимый многочлен степени 2 над $GF(2)$ — это $x^2+x+1$; деление $x^4+x+1$ на $x^2+x+1$ даёт ненулевой остаток. Следовательно, $h(x)$ **неприводим**. 

#### Шаг 2 — Примитивность $h(x)$

Порядок $h(x)$ — наименьшее $e$ такое, что $h(x) \mid x^e + 1$.

Проверяем делители $2^4 - 1 = 15$, т.е. $e \in \{1, 3, 5, 15\}$:

- $x^1 + 1$: степень 1, $h(x)$ не делит 
- $x^3 + 1 = (x+1)(x^2+x+1)$: $h(x)$ не входит как множитель 
- $x^5 + 1 = (x+1)(x^4+x^3+x^2+x+1)$: $h(x)$ не делит   
- $x^{15} + 1$: $h(x)$ делит по построению поля

Порядок $h(x)$ равен $15 = 2^4 - 1$ $\Rightarrow$ $h(x)$ **примитивен** $\Rightarrow$ **код является кодом максимальной длины**.

### Минимальное расстояние


Ненулевые кодовые слова имеют вес только двух значений:

$$w \in \left\{2^{m-1} - 1,\; 2^{m-1}\right\} = \{7,\; 8\}$$

- Слов веса $7$: ровно $2^{m-1} - 1 = 7$  
- Слов веса $8$: ровно $2^{m-1} = 8$  
- Итого ненулевых слов: $7 + 8 = 15 = 2^4 - 1$ 

$$d_{\min} = \min_{c \neq 0} w(c) = 7$$
