## Задача 

По минимальный многочленам $M_1(x)$ и $M_3(x)$ построить порождающий полином $g(x)$, порождающую матрицу $G$ и проверить, что $G * H^T = 0$


Для примитивного элемента $\alpha \in \mathrm{GF}(2^4)$, где $\alpha^4 = \alpha + 1$:

$$M_1(x) = x^4 + x + 1 \quad \text{(корни: } \alpha,, \alpha^2,, \alpha^4,, \alpha^8\text{)}$$

$$M_3(x) = x^4 + x^3 + x^2 + x + 1 \quad \text{(корни: } \alpha^3,, \alpha^6,, \alpha^{12},, \alpha^9\text{)}$$


Порождающий многочлен строится как наименьшее общее кратное минимальных многочленов. Поскольку $M_1(x)$ и $M_3(x)$ взаимно просты:

$$g(x) = \mathrm{НОК}(M_1(x),, M_3(x)) = M_1(x) \cdot M_3(x)$$

Перемножаем над $\mathrm{GF}(2)$:

$$g(x) = (x^4 + x + 1)(x^4 + x^3 + x^2 + x + 1)$$

Раскрываем скобки:

$$= x^8 + x^7 + x^6 + x^5 + x^4$$ $$\quad\oplus x^5 + x^4 + x^3 + x^2 + x$$ $$\quad\oplus x^4 + x^3 + x^2 + x + 1$$
